# SHADOW

일정 본체 주변의 준비·이동·회복 시간을 그림자로 보여주는 개인용 캘린더입니다.

## Run locally

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run typecheck
npm run test -- --run
npm run build
npx playwright install chromium
npm run test:e2e
```

일정 데이터는 외부 서버로 전송되지 않고 브라우저 `localStorage`에만 저장됩니다.

## 동작 기준

- 시간표는 00:00~24:00 전체를 표시합니다. 준비·귀가·회복 그림자가 자정을 넘으면 전날/다음 날에도 이어집니다.
- 일정을 클릭하거나 Enter 키로 편집할 수 있습니다. 드래그는 잡은 위치를 유지하며 15분 단위로 이동하고, Escape 또는 포인터 취소로 이동을 취소합니다.
- 겹치는 일정은 나란히 표시합니다. 충돌 합계는 현재 보이는 날짜에서 일정 쌍마다 한 번 계산합니다. 3개 이상 겹치면 서로 다른 쌍의 시간이 합산됩니다.
- 모든 시간·비용은 0 이상의 정수이며 그림자는 각 720분, 비용은 항목별 10,000,000원까지 입력할 수 있습니다. 종료 시각의 ‘자정에 종료’는 24:00입니다.
- 유형 기본값을 바꿔도 기존 일정의 시간·비용은 유지됩니다. 사용 중인 유형과 마지막 남은 유형은 삭제할 수 없습니다.
- 모바일에서도 유형 설정이 가능합니다. 편집 패널은 키보드 포커스를 안에 유지하고 Escape로 닫은 뒤 원래 버튼으로 돌아갑니다.
- 손상되거나 지원하지 않는 저장 데이터는 자동으로 덮어쓰지 않습니다. 확인 후 초기화해야 편집을 재개할 수 있습니다. 저장 공간 부족 시 오류를 표시하며 ‘저장 재시도’로 메모리의 변경사항을 다시 저장합니다.

## 검증 범위

`npm run verify`는 lint, TypeScript, 단위/컴포넌트 테스트, 프로덕션 빌드를 실행합니다.
Chromium E2E는 일정 저장·복원, 정확한 드래그 이동·취소, 충돌 배치, 새벽 일정, 데이터 보존, 모바일 유형 관리, 키보드 포커스 및 axe 접근성을 검증합니다.
Playwright 테스트는 같은 포트를 사용하는 여러 명령을 동시에 실행하지 말고 한 명령으로 실행해 주세요.

Windows의 제한된 실행 환경에서 기존 `dist`를 정리하는 단계가 종료될 경우, `npm.cmd run build -- --emptyOutDir false`로 기존 파일 삭제 없이 빌드할 수 있습니다. 이 방법은 이전 해시 파일을 남기므로 배포용 결과물은 새 출력 폴더에서 생성하세요.

브라우저 데이터를 직접 지우면 복구할 수 없습니다. 클라우드 동기화와 자동 백업은 제공하지 않습니다.
